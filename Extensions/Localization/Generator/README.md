# Dosaic.Extensions.Localization.Generator

`Dosaic.Extensions.Localization.Generator` is a Roslyn `IIncrementalGenerator` that runs at compile time to discover all properties annotated with `[LocalizedName]` and emit a static `EntityPropertyLabels` lookup class into the consuming project. It can also write per-culture JSON translation files to disk during the build.

## Installation

```shell
dotnet add package Dosaic.Extensions.Localization
dotnet add package Dosaic.Extensions.Localization.Generator
```

Or as `PackageReference` entries in your `.csproj`:

```xml
<PackageReference Include="Dosaic.Extensions.Localization" Version="" />
<PackageReference Include="Dosaic.Extensions.Localization.Generator" Version=""
                  OutputItemType="Analyzer" ReferenceOutputAssembly="false" />
```

## Features

- **Incremental generation** — uses `IIncrementalGenerator` for fast, cache-friendly incremental builds; only reruns when annotated properties change
- **Type-safe API** — generates `Get<T>(Expression<Func<T, object>>)` overloads that resolve labels without magic strings
- **Configurable default culture** — `EntityPropertyLabels.DefaultCulture` can be set at runtime; defaults to `"en"`
- **Fallback** — returns the property name when no translation is registered for the requested culture
- **JSON export** — writes a translation JSON file per culture when MSBuild properties are configured

## Generated output

Given:

```csharp
public class Order
{
    [LocalizedName(en: "Order Number", de: "Bestellnummer")]
    public string OrderNumber { get; set; }
}
```

The generator emits `EntityPropertyLabels.g.cs`:

```csharp
// <auto-generated/>
using System.Collections.Generic;

namespace Dosaic.Extensions.Localization
{
    public static partial class EntityPropertyLabels
    {
        private static readonly Dictionary<string, Dictionary<string, string>> Labels =
            new Dictionary<string, Dictionary<string, string>>()
            {
                ["Order.OrderNumber"] = new Dictionary<string, string> { ["en"] = "Order Number", ["de"] = "Bestellnummer" },
            };

        public static string DefaultCulture = "en";

        public static string Get(string typeName, string propertyName)
            => Get(typeName, propertyName, DefaultCulture);

        public static string Get(string typeName, string propertyName, string culture) { ... }

        public static string Get<T>(Expression<Func<T, object>> propertySelector)
            => Get<T>(propertySelector, DefaultCulture);

        public static string Get<T>(Expression<Func<T, object>> propertySelector, string culture) { ... }
    }
}
```

## JSON export

The generator can write translation files to disk on every build. Declare the output paths as MSBuild properties and expose them to the generator via `CompilerVisibleProperty`:

```xml
<PropertyGroup>
  <LocalizationJsonDeOutputPath>$(MSBuildProjectDirectory)\localization.de.json</LocalizationJsonDeOutputPath>
  <LocalizationJsonEnOutputPath>$(MSBuildProjectDirectory)\localization.en.json</LocalizationJsonEnOutputPath>
</PropertyGroup>

<ItemGroup>
  <CompilerVisibleProperty Include="LocalizationJsonDeOutputPath" />
  <CompilerVisibleProperty Include="LocalizationJsonEnOutputPath" />
</ItemGroup>
```

Either property can be omitted to skip output for that culture. When set, the file is written on every compilation that touches an annotated property.

### Output format

```json
{
  "Order": {
    "OrderNumber": "Bestellnummer"
  },
  "Customer": {
    "Name": "Name",
    "Address": "Adresse"
  }
}
```

Properties are grouped by type name. The value is the translation for the configured culture, falling back to the property name if no translation is registered.

## How it works

1. **Attribute discovery** — `ForAttributeWithMetadataName` filters syntax nodes to properties carrying `[Dosaic.Extensions.Localization.LocalizedNameAttribute]`
2. **Symbol extraction** — resolves each node to `IPropertySymbol`, reads the containing type name and the `en`/`de` constructor arguments
3. **Source emission** — `RegisterSourceOutput` collects all results and emits `EntityPropertyLabels.g.cs` into the compilation
4. **JSON writing** — reads `LocalizationJsonDeOutputPath` / `LocalizationJsonEnOutputPath` from `AnalyzerConfigOptionsProvider.GlobalOptions` and writes grouped JSON files to disk if paths are set
